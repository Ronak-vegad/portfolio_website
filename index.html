CollegeChatbot
RAG / LLM

RAG-powered chatbot for BVM Engineering College. Students ask any college question and get accurate, sourced answers — not hallucinations.

⚡ what I actually solved
Problem: College FAQs are inconsistently worded — same question phrased 10 different ways.
Solution: Added query normalization + fuzzy matching + spell correction before retrieval. Tuned FAISS similarity threshold to cut hallucinations on out-of-scope questions. Built content-aware chunking in the ingest pipeline for cleaner, more accurate retrieval.

Voice AI Agent
Voice

Voice-controlled AI agent built during internship at Mem0 AI. Fully on-device inference pipeline — speech-to-text, reasoning, and speech output without sending data to the cloud.

⚡ what I actually solved
Problem: Most voice agents depend on cloud APIs — adds latency and exposes user data.
Solution: Full pipeline on-device using faster-whisper for speech-to-text (GPU-accelerated), llama3.2:3b via Ollama for reasoning, and TTS output. Under 2s response time on consumer hardware. Delivered as a Substack article + demo video.

AI Chatbot — ReAct Agent
Full-stack

Full-stack ChatGPT-style AI chatbot with file upload, persistent memory, and a ReAct agent that reasons step-by-step before responding — not just next-token generation.

⚡ what I actually solved
Problem: Basic chatbots have no memory across sessions and can't work with user-uploaded files.
Solution: ReAct architecture (Reason → Act → Observe loop) with ChromaDB for persistent vector memory across sessions. File upload → embed → retrieve on demand. FastAPI backend, React frontend.

SmartBilling
OCR

OCR-powered billing automation. Upload an invoice PDF → AI extracts all structured data → stores it in a local encrypted database. End-to-end billing pipeline.

⚡ what I actually solved
Problem: OCR alone is inaccurate on messy or varied invoice formats; cloud solutions raise privacy concerns.
Solution: Two-stage pipeline — PaddleOCR for text extraction (stage 1), local LLM for structured parsing and error correction (stage 2). SQLite with encryption for secure storage.
